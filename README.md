1. Εισαγωγή

Ο παρών κώδικας υλοποιεί ένα απλό σύστημα διαχείρισης βιβλιοθήκης σε γλώσσα προγραμματισμού C++.
Ο χρήστης μπορεί μέσω ενός μενού να προσθέτει, να αναζητά, να εμφανίζει, να τροποποιεί, να διαγράφει και να ταξινομεί βιβλία, καθώς και να αποθηκεύει τα δεδομένα σε αρχείο.

Ο κώδικας βασίζεται σε αντικειμενοστραφή προγραμματισμό και χρησιμοποιεί δυναμική διαχείριση μνήμης.


2. Βιβλιοθήκες που χρησιμοποιούνται

cpp
#include <iostream>
#include <string>
#include <fstream>
#include <limits>


iostream: Είσοδος και έξοδος δεδομένων (cin, cout)
string: Χρήση συμβολοσειρών
fstream: Αποθήκευση δεδομένων σε αρχείο
limits: Χρήση της `numeric_limits` για σωστή διαχείριση του input buffer


3. Κλάση Book

Η κλάση Book αναπαριστά ένα βιβλίο της βιβλιοθήκης.

3.1 Ιδιωτικά Μέλη (Private)

cpp
string title;
string author;
int year;
int id;


title: Τίτλος βιβλίου
author: Συγγραφέας
year: Έτος έκδοσης
id: Μοναδικό αναγνωριστικό βιβλίου

3.2 Constructors

cpp
Book();
Book(string t, string a, int y, int i);


Ο default constructor αρχικοποιεί όλα τα πεδία με μηδενικές ή κενές τιμές.
Ο παραμετρικός constructor αρχικοποιεί το αντικείμενο με τιμές που δίνει ο χρήστης.


3.3 Setters & Getters

Χρησιμοποιούνται για την ασφαλή πρόσβαση και τροποποίηση των δεδομένων του βιβλίου.

Παραδείγματα:

cpp
void setTitle(const string& t);
string getTitle() const;



3.4 Συνάρτηση print()

cpp
void print() const;


Εμφανίζει όλες τις πληροφορίες του βιβλίου σε μορφοποιημένη μορφή στην οθόνη.



4. Κλάση Library

Η κλάση Library διαχειρίζεται μια συλλογή από αντικείμενα `Book`.



4.1 Ιδιωτικά Μέλη

cpp
Book* books;
int size;
int capacity;


books: Δυναμικός πίνακας βιβλίων
size: Τρέχων αριθμός βιβλίων
capacity: Μέγιστη χωρητικότητα πίνακα


4.2 Συνάρτηση resize()

cpp
void resize();


Αυξάνει δυναμικά το μέγεθος του πίνακα όταν γεμίσει.
Η χωρητικότητα διπλασιάζεται κάθε φορά που δεν επαρκεί ο χώρος.


4.3 Constructors & Destructor

cpp
Library();
~Library();


Ο constructor αρχικοποιεί τον πίνακα ως nullptr
Ο destructor αποδεσμεύει τη δεσμευμένη μνήμη


4.4 Βασικές Συναρτήσεις

addBook()

cpp
void addBook(const Book& b);


Προσθέτει νέο βιβλίο στη βιβλιοθήκη.


findById()

cpp
int findById(int searchID) const;


Αναζητά βιβλίο με βάση το ID και επιστρέφει τη θέση του στον πίνακα.



printAll()

cpp
void printAll() const;


Εμφανίζει όλα τα βιβλία της βιβλιοθήκης.



deleteByID()

cpp
void deleteByID(int delID);


Διαγράφει βιβλίο με βάση το ID μετακινώντας τα υπόλοιπα στοιχεία.


searchAndPrintByID()

cpp
void searchAndPrintByID(int searchID) const;


Αναζητά και εμφανίζει συγκεκριμένο βιβλίο.

editById()

cpp
void editById(int editId);


Επιτρέπει την τροποποίηση:

Τίτλου
Συγγραφέα
Έτους έκδοσης


sortByTitle()

Ταξινομεί τα βιβλία αλφαβητικά βάσει τίτλου (Bubble Sort).



sortByYear()

Ταξινομεί τα βιβλία με βάση το έτος έκδοσης.


saveToFile()

cpp
void saveToFile(const string& filename) const;


Αποθηκεύει τα βιβλία σε αρχείο κειμένου με μορφή:


ID | Title | Author | Year




5. Συνάρτηση main()

Η main() υλοποιεί ένα μενού επιλογών που επιτρέπει στον χρήστη:

1. Προσθήκη βιβλίου
2. Αναζήτηση βιβλίου με ID
3. Εμφάνιση όλων των βιβλίων
4. Διαγραφή βιβλίου
5. Επεξεργασία βιβλίου
6. Ταξινόμηση κατά τίτλο
7. Ταξινόμηση κατά έτος
8. Αποθήκευση σε αρχείο
9. Έξοδο από το πρόγραμμα

Η εκτέλεση συνεχίζεται μέχρι ο χρήστης να επιλέξει έξοδο.



 6. Συμπέρασμα

Ο κώδικας υλοποιεί με επιτυχία ένα λειτουργικό σύστημα βιβλιοθήκης, αξιοποιώντας:

 Αντικειμενοστραφή προγραμματισμό
 Δυναμική μνήμη
 Διαχείριση αρχείων
 Διαδραστικό μενού χρήστη

Αποτελεί μια ολοκληρωμένη βάση για περαιτέρω επεκτάσεις, όπως φόρτωση δεδομένων από αρχείο ή χρήση STL containers.
